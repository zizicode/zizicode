## 👨‍💻 Sobre mí

Soy desarrollador Full Stack con **más de 5 años de experiencia** construyendo aplicaciones web y móviles. Trabajo principalmente con el stack **MERN** (MongoDB, Express, React y Node.js), y lo que más disfruto es crear soluciones que no solo funcionen bien, sino que también se sientan bien al usarlas.

Me gusta entender un producto de punta a punta: pensar la interfaz, diseñar la API, modelar los datos y verlo funcionando en manos de personas reales.

- 🚀 Apasionado por **Node.js** y todo el ecosistema JavaScript
- 🌐 Desarrollo **frontend y backend** desde cero
- 📱 Apps móviles multiplataforma con **React Native**
- ☁️ Despliegue y servicios en la nube con **Azure** y **Firebase**
- 🎨 Cuido el diseño y la experiencia de usuario, no solo el código
